# Industry videos (Elementor / WordPress)

Upload short muted loops here (or to WP Media Library) and point each
`<source src="...">` in the Industry Expertise section to the file URL.

Suggested filenames:
- smart-city.mp4
- manufacturing.mp4
- utilities.mp4
- logistics.mp4
- oil-gas.mp4
- agriculture.mp4
- mining.mp4

Specs: 4–8 seconds, muted, H.264 MP4, ≤3 MB, 720p–1080p.
